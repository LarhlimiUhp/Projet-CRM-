## 📋 À propos

Ce dépôt contient un **compte rendu de recherche complet** sur les solutions CRM (Customer Relationship Management) déployées au Maroc. L'étude analyse le marché à travers le prisme des données chiffrées, des tendances sectorielles et du cadre réglementaire marocain (loi 09-08).

L'objectif est de fournir aux **étudiants, chercheurs, décideurs et professionnels** une vue d'ensemble structurée et sourcée pour comprendre :

- L'état d'adoption des CRM par les entreprises marocaines
- Les principaux produits présents sur le marché
- Les critères de choix selon la taille et le secteur d'activité
- Les tendances à l'horizon 2030
